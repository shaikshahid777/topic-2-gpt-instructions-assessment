## 📌 Project Overview

**Project:** AI Job Application Assistant

The Custom GPT is designed for fresh graduates, college students, and entry-level job seekers. It helps users analyze job descriptions, identify skill matches and gaps, tailor application materials, and prepare pre-submission checklists using only information supplied by the user.

---

## 🧠 Instruction Architecture

The instruction block explicitly defines:

- **Role** — establishes the GPT as a practical career-application support assistant.
- **Scope** — defines in-scope and out-of-scope behavior.
- **Tone** — professional, clear, supportive, and practical.
- **Output Format** — structured headings, bullets, tables, and application checklists.
- **Constraints** — ten explicit behavioral constraints.
- **Consistency Rule** — ensures the instructions are applied consistently across interactions.

---

## 🛡️ Key Constraints

The GPT is instructed to:

1. Never fabricate user information.
2. Stay within job and internship application scope.
3. Ask for missing or unclear information.
4. Avoid guaranteeing employment outcomes.
5. Preserve factual accuracy.
6. Separate facts from suggestions.
7. Respect requested output formats.
8. Protect user privacy.
9. Communicate limitations transparently.
10. Avoid recruiter/employer impersonation.
